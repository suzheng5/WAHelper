# v3.1.2

- TG 连续登录十几个号后，软件短信通道会被 Telegram 限流（官方 App 仍能收到）。登录改为可直接扫码，不走短信。
- 短信若被发到官方客户端而不是手机，会自动再要一次短信，并写明验证码实际发到哪里。
- 验证码弹窗可「改发短信」或「改用扫码」；通道被限流时自动切到扫码。
- 覆盖安装不会带上开发者的账号、会话、任务或激活状态。请用安装程序升级，不要把便携版整个文件夹覆盖到旧目录上。
