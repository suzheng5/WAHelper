TG 任务回退一天工具
====================

用途
----
误点“一键开始下一天”后，将当前全部 TG 文件夹任务退回上一天。

使用步骤
--------
1. 完全退出“超群小帮手”。
2. 双击“TG任务回退一天.exe”。
3. 选择软件根目录：
   此目录内应包含 telegram\config.json 和 telegram\data\schedules.json。
4. 检查工具显示的任务、当前文件和上一天文件。
5. 点击“回退全部候选任务”并确认。
6. 完成后重新打开主程序，到任务管理中检查，再手动开始需要继续的任务。

回退行为
--------
1. 每个文件夹任务只回退一天。
2. 第一天的任务不会处理。
3. 工具会重新读取上一天 TXT，重新生成任务话术。
4. 回退后的任务统一暂停，并从上一天第 1 步开始。
5. 已经发出的错误日期消息不会撤回，重新开始前请注意避免重复发送。

备份与恢复
----------
操作前自动在 telegram\data 下生成：

  schedules.json.bak_day_rollback_年月日_时分秒

如果需要恢复：
1. 完全退出主程序。
2. 备份当前 schedules.json。
3. 将上述备份文件复制并改名为 schedules.json。
4. 重新启动主程序。

限制
----
“一键下一天”时已经处于最后一天并被自动删除的任务，不在当前 schedules.json 中，
本工具无法从当前配置恢复，只能使用操作前已有的旧备份恢复。
